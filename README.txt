M9 변경 사항
1. 2일차 UE에서 같은 CH+원문으로 이미 줍줍 기록이 있으면, 다시 줍줍 요구 없이 다음 카드로 이동.
   이전 기록이 없는 경우 원본 담기/문장 변형을 선택하도록 하고 강제 패스 버튼은 숨김.
2. IPA 사전에 없는 단어는 영어 철자로 보이되 다른 단어는 정상 IPA 표시.
   생성된 IPA는 사용자가 직접 검토/수정할 수 있습니다. (보여주는 철자는 IPA가 아닙니다.)
3. 변형 팝업의 이전 줍줍 문장마다 '수정' 버튼 제공. 기존 항목의 ID를 유지하며 선택한 항목만 수정.
4. 새 문장을 담을 때마다 '줍줍 문장을 하나 더 추가할까요?' 질문.
   '확인'은 추가 작성, '취소'는 이번 작업 완료(미션 진행이었다면 다음 카드).
5. 줍줍 선택 팝업 버튼 높이 60px, 편집창 버튼도 확대.
6. 학습/줍줍 각 탭에서 챕터 1~6, 7~12 를 6×2 배열로 표시; 복수 선택 및 전체 보기.
7. 줍줍 통계를 총합/MS/RC/기타로 분리. j.section 기존 값으로 분류하며 저장 구조 변경 없음.
8. 녹음 체감 지연은 원인 분석만 수행. 정상 작동하는 MediaRecorder, getUserMedia(audio:true),
   onstart+350ms 안내, 마이크 매회 열기/닫기 등 기존 코드는 변경하지 않음.
