Stack Up M8 — 스터디 인증 27일 기준으로 관리자 집계 수정

기준 파일: 사용자에게 이전에 전달한 M7의 app.js
변경: app.js만 교체. style.css, index.html, data.js, manifest.json 변경 없음.

[변경 사항]
1. getScheduledMissionDays(): 기존 taskOffsets와 KST 날짜 계산을 재사용하여 60개 미션을 27개 날짜로 그룹화.
2. getMissionDayProgress(): 하루에 배정된 세부 미션을 모두 완료하면 그날을 1일로 집계.
3. 관리자 미션 완료율: x/60개 -> x/27일, 달성률도 27일 기준.
4. 관리자 패널티: 세부 미션별이 아닌 날짜별 1회, 그날 모든 미션을 한국시간 다음날 02:00까지 완료해야 패널티 없음.

[보존]
- Firebase completedTasks 저장 구조(각 CHxx-일차 별 ISO 시각)를 유지, 데이터 변환/삭제 없음.
- 오늘 미션, 전날 미션, 녹음/재생, 성취도 팝업, 자동학습, 줍줍, 카드 진도 및 CSS는 변경하지 않음.
- 기존 세부 미션 카드 60개는 그대로 표시되며, 관리자 집계 단위만 27일로 변경.

[검증]
- JS 문법 검사 및 27일/60개 집계와 미국/한국 시간대, 01:59/02:00 경계를 별도 테스트.
- 실제 회원 데이터/Firebase를 변경하거나 iPhone에서 직접 테스트하지는 않음.

[배포]
- app.js 파일만 GitHub에 업로드.
- index.html의 app.js?v=... 값만 새 문자열로 수정해 캐시 갱신.

[주의]
